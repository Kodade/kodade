# Support

- Use [GitHub Discussions](https://github.com/Kodade/kodade/discussions) for
  setup questions, ideas, and general help.
- Use the issue templates for reproducible bugs and concrete feature requests.
- Use [private vulnerability reporting](SECURITY.md) for security concerns.

Ködade is an independent open-source project. Support for Claude Code, Codex,
and other agent accounts, subscriptions, or provider outages must come from the
respective provider.
