# Third-party notices

Ködade depends on open-source projects that remain subject to their respective
licenses. `pnpm-lock.yaml` and `src-tauri/Cargo.lock` record the exact JavaScript
and Rust dependency versions used by this source tree. This document is a
source-level inventory. The complete generated distribution bundle is under
[`licenses/dependencies/generated/`](licenses/dependencies/generated/) and is
packaged into `Contents/Resources/legal/dependencies/` in public apps.

The production dependency set was reviewed before the first public release.
Declared licenses include Apache-2.0, MIT, BSD-2-Clause, BSD-3-Clause, ISC,
MPL-2.0, Python-2.0, SIL Open Font License 1.1, Unicode-3.0, Zlib, CC0-1.0,
CDLA-Permissive-2.0, and compatible dual-license combinations. No dependency
with a missing license declaration was found; Ködade's own package metadata now
declares Apache-2.0.

## Dependency license reports

The JavaScript report uses pnpm's production dependency inventory and retains
each package's distributed license, copyright, and notice files. Version-pinned
upstream overrides cover packages whose npm tarballs omit their license text.
The Rust report is generated by `cargo-about` for the Apple Silicon target with
the public app's default features. Its SPDX resolution retains package-specific
copyright and attribution text where available.

Regenerate and verify the complete bundle with:

```bash
cargo install cargo-about --version 0.9.1 --locked --features cli
pnpm licenses:generate
pnpm licenses:verify
```

The generated manifest pins the input and output hashes, package counts, target,
and tool versions. Public frontend builds and resource staging both reject a
missing, changed, or stale report.

If a vendored or packaged component is added, its required copyright and
license notices must be added here or shipped alongside that component before a
release is distributed.
